Portföy Paneli

Rebalancing botunun okuduğu config.yaml dosyasını doğrudan buradan düzenle. Değişiklikler GitHub'a kaydedilir, bot bir sonraki çalışmasında bunları kullanır.

1. Repoya bağlan

Token hiçbir yere kaydedilmez, doğrudan tarayıcından GitHub'a gönderilir.

Token yoksa github.com/settings/tokens adresinden "classic" bir token oluştur, "repo" yetkisini işaretle.

2. Araçlar

Hedef ağırlıklar toplamda %100 olmalı.

Tür Kod Ad Hedef % Miktar
Toplam hedef ağırlık %0.0

3. Rebalancing eşiği

Not: Kaydettiğinde config.yaml içindeki açıklama satırları (# ile başlayanlar) kaybolur, sadece veriler korunur.

Bu panel doğrudan tarayıcında çalışır, hiçbir sunucuya veri göndermez — sadece GitHub API'sine.
